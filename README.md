# LifeOPS

Sistema pessoal desenvolvido em Python para organizar tarefas, compromissos e gastos.

O projeto foi criado com o objetivo de praticar desenvolvimento backend e, ao mesmo tempo, construir uma aplicação útil para o dia a dia.

## Funcionalidades

- Cadastro de tarefas
- Conclusão e exclusão de tarefas
- Cadastro de compromissos
- Exclusão de compromissos
- Registro de gastos
- Cálculo do total de gastos
- Resumo geral
- Persistência dos dados com SQLite
- Tratamento básico de erros

## Tecnologias

- Python
- SQLite
- SQL
- Git
- uv
